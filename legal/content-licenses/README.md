# Content licensing gate

No copyrighted score, lyrics, album artwork, or recording is distributed by this repository.

“Holocene” by Bon Iver is an import target only. A user may open a MusicXML, MXL, MIDI, or portable `.score` document they are authorized to use; it remains device-local unless they explicitly export it. Do not add a bundled Holocene asset until a separate `holocene.md` records written distribution rights for the arrangement, notation, lyrics, territories, term, offline caching, and hosted delivery.

Developer-owned licensed fixtures belong under `tests/fixtures/licensed/`. That directory is ignored by Git and excluded from builds.
