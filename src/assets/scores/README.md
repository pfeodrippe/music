# Bundled score library

These files are intentionally limited to scores with explicit public-domain or
CC0 metadata. They are embedded into release binaries and remain available
offline.

Do not add a score solely because the underlying composition is old. The
specific digital engraving or arrangement must also include a compatible
rights statement and a durable source record here.
